GLOSSARY - Cosmic Eye Animation (Professional ASCII Art)
============================================================

--- GENERAL TERMS ---
ASCII               : Image drawn with text characters
FPS                 : Frames Per Second
SuperSample         : Anti-aliasing - computing multiple sub-pixels per cell and averaging
Tkinter             : Python's standard GUI library
NumPy               : Fast array/matrix math library
RNG                 : Random Number Generator
RGB                 : Red-Green-Blue color channels
Linear Interpolate  : Blending between two values
Smoothstep          : Smooth 0->1 transition curve (ease function)
Bloom               : Glow effect where bright areas bleed light into surroundings
Vignette            : Darkening toward the edges of the screen
Tone Mapping        : Compressing brightness into 0-1 range (exponential curve)
Catchlight          : Bright light reflection inside the eye
Procedural          : No image files - everything generated with math
Fractal Texture     : Multi-layer noise texture for organic detail
Bilinear Sample     : Smooth texture lookup at UV coordinates

--- DISPLAY SETTINGS (CONFIGURATION) ---
FONT_SIZE           : Character font size (pixels)
FRAME_RATE          : Target frames per second
SUPER_SAMPLE        : Anti-aliasing quality (2x2 sub-pixels per cell)
ASPECT_RATIO        : Width-to-height ratio multiplier
MAX_ROW_COUNT       : Maximum number of text rows to display
TKINTER_FRAME_BUDGET_MS : Time budget per frame for Tkinter drawing (milliseconds)

--- TIMELINE CONFIGURATION ---
TIME_EYE_OPEN_START : Time when eye starts opening (seconds)
TIME_EYE_OPEN_DURATION : Duration of eye opening animation
TIME_BLINK          : Time when natural blink occurs
TIME_ZOOM_START     : Time when zoom into pupil begins
TIME_ZOOM_DURATION  : Duration of zoom animation
ZOOM_FINAL_LEVEL    : Final zoom level when in space
TIME_SPACE_SCENE    : Time when space scene becomes visible
TIME_HEART_MORPH_START : Time when nebula starts morphing into heart
TIME_HEART_MORPH_DURATION : Duration of heart morphing animation

--- EYE GEOMETRY ---
EYE_HALF_WIDTH      : Half-width of the eye opening
EYELID_UPPER_HEIGHT : Height of upper eyelid when open
EYELID_LOWER_HEIGHT : Height of lower eyelid when open
IRIS_RADIUS         : Radius of the iris (colored part)
PUPIL_BASE_RADIUS   : Base radius of the pupil (black center)
STAR_SPREAD_BASE    : Base scale for star distribution
STAR_SPREAD_MAXIMUM : Maximum scale for star distribution

--- ASCII CHARACTER RAMP ---
BRIGHTNESS_RAMP     : Characters ordered from dark to bright
RAMP_MAX_INDEX      : Length of brightness ramp minus 1
CHARACTER_INDEX_MAP : Dictionary mapping character to ramp index
COLOR_QUANTIZATION_LEVELS : Number of color steps per channel (24)

--- RANDOM GENERATORS ---
main_random_generator : NumPy random generator (fixed seed for reproducibility)
physics_random_generator : Python random generator (for shooting stars)

--- MATH HELPER FUNCTIONS ---
smooth_step()       : Smooth interpolation from min to max
ease_curve()        : Scalar smoothstep easing (ease in, ease out)
zoom_progress()     : Calculate zoom progress (0-1) based on timeline
linear_interpolate() : Linear interpolation between two values
upscale_2d_smooth() : Smoothly upscale small random grid to target size
normalize_noise()   : Normalize noise into 0-1 range with standard deviation

--- TEXTURE GENERATION ---
generate_fractal_texture() : Create multi-layer fractal 2D texture
generate_1d_noise() : Generate smooth 1D noise from random grid
bilinear_sample()  : Smooth texture lookup at UV coordinates

--- TEXTURE VARIABLES ---
TEXTURE_SKIN        : Multi-octave fractal texture for skin
TEXTURE_GRAIN       : General grain texture for nebula and details
TEXTURE_WHITE_NOISE : Pure random noise for eyebrows and specks
TEXTURE_VEIN        : Vein-like line texture (ridged noise)
TEXTURE_VEIN2       : Second vein texture variant

--- IRIS TEXTURE ARRAYS ---
ANGULAR_NOISE_SIZE  : Length of angular noise tables (4096)
IRIS_FIBER_1        : First layer of iris fiber angular noise
IRIS_FIBER_2        : Second layer of iris fiber angular noise
IRIS_WOBBLE         : Wobble pattern for iris collarette boundary
IRIS_CRYPT          : Dark pit/spot pattern in iris

--- STAR FIELD VARIABLES ---
STAR_COUNT          : Total number of stars (3200)
STAR_POS_X          : Star X position (-1 to 1)
STAR_POS_Y          : Star Y position (-1 to 1)
STAR_DEPTH          : Star depth (distance from camera)
STAR_BRIGHTNESS     : Star brightness (power-law distribution)
STAR_COLOR          : Star color (blue-white to golden gradient)
STAR_TWINKLE_PHASE  : Random phase for twinkling
STAR_TWINKLE_FREQ   : Twinkling frequency per star

--- GAZE KEYFRAMES ---
GAZE_KEYFRAMES      : List of (time, gaze_x, gaze_y) keyframes

--- EYELASH ARRAYS ---
UPPER_LASHES        : List of upper eyelash definitions
UPPER_LASH_COUNT    : Number of upper eyelashes (44)
LOWER_LASHES        : List of lower eyelash definitions
LOWER_LASH_COUNT    : Number of lower eyelashes (20)

--- GLOBAL STATE ---
global_state        : Dictionary for global state variables
world_state         : Animation state dictionary (time, shooting stars, comet)

--- SHOOTING STARS ---
shooting_stars      : List of active ShootingStar objects
ShootingStar        : Class representing shooting star/comet
world_state['last_time'] : Last frame time
world_state['next_shooting_star'] : Time of next shooting star
world_state['comet_active'] : Whether comet is visible

--- GEOMETRY COORDINATES (initialize_display) ---
cell_width          : Pixel width of one character cell
cell_height         : Pixel height of one character cell
row_count           : Number of text rows
col_count           : Number of text columns
canvas_width        : Total canvas width in pixels
canvas_height       : Total canvas height in pixels
grid_width          : Width of supersampled grid
grid_height         : Height of supersampled grid
coord_x             : X coordinate of each sub-pixel (normalized)
coord_y             : Y coordinate of each sub-pixel (normalized)
radius_subpixel     : Distance from center for sub-pixels
cell_center_x       : X coordinate of cell centers (normalized)
cell_center_y       : Y coordinate of cell centers (normalized)
radius_cell         : Distance from center for cell centers
hash_cell           : Pseudo-random value per cell (for dithering)

--- ANIMATION FUNCTIONS ---
initialize_display() : Set up display size, coordinate grids, geometry
blink_curve()       : Blink animation curve (0=open, 1=closed)
eyelid_openness()   : Eyelid openness over time (0=closed, 1=open)
gaze_direction()    : Compute current gaze direction (gx, gy)
eyelid_edge_position() : Calculate eyelid edge positions at given x
reset_animation()   : Reset all animation state to initial values
update_world_state() : Update star positions, shooting stars, comet

--- RENDERING FUNCTIONS ---
heart_nebula_renderer() : Render heart-shaped nebula cloud
eye_scene_renderer() : Render complete eye scene
render_frame()      : Render one complete frame
apply_bloom()       : Apply bloom/glow effect
render_stars()      : Render twinkling stars as characters
render_shooting_star() : Render shooting star/comet with trail
render_eyelashes()  : Render eyelashes as characters
plan_cell_updates() : Determine which cells need redrawing
main()              : Main entry point, initialize window and loop
